# 📚 Sistema Biblioteca

Sistema de gerenciamento de biblioteca desenvolvido em Java com o objetivo de praticar conceitos de programação orientada a objetos (POO).

## 🚀 Sobre o projeto

O projeto permite realizar operações básicas de uma biblioteca, como cadastro e gerenciamento de livros e outras informações relacionadas ao sistema.

Foi desenvolvido durante meus estudos de Java, buscando colocar em prática conceitos aprendidos ao longo do desenvolvimento.

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git e GitHub

## 📌 Conceitos praticados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Getters e Setters
- Construtores
- Métodos
- Herança e Polimorfismo
- `toString()`
